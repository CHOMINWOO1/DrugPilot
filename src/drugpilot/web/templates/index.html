    DB
    데이터 소스

    데이터 소스 연결 현황

    보고서의 데이터 소스를 어댑터 구현·설정 상태에 따라 구분합니다. 단계 표시는 해당 소스를 직접 조회하는 에이전트이며, MA3는 저장된 상위 근거를 감사합니다. ‘어댑터 활성’은 네트워크 응답 보장이 아니라 호출 경로가 준비되었다는 뜻이며, 실제 조회 여부와 성공·캐시·fallback은 실행별 근거 기록에서 확인합니다.

    왜 네 그룹으로 나누나?

    활성은 현재 실행 가능한 어댑터, 필요 시는 단계·가설·식별자·탐색 경로가 맞을 때만 실행하는 어댑터, 설정 필요는 키·라이선스·로컬 데이터·사이드카가 필요한 어댑터, 평가 전용은 연구 실행 어댑터에 연결하지 않고 별도 benchmark 정책에 분리 등록한 데이터셋입니다.

    매 실행 시 단계에 해당하는 소스를 후보로 검토하고, 실제 호출은 MA1 기본 조회·Pharos·맥락 DB·MA2 후보 DB의 결정론적 라우터가 선택합니다. Orchestrator는 실행 단계를 고정하며, 맥락 조회는 별도의 호출 수·시간 예산도 적용합니다. 예: 세포 맥락→HCA/CELLxGENE, 발현·Tbio→GTEx/ARCHS4, 네트워크→STRING/BioGRID, Pharos·TDL 요청→Pharos, 재창출→DrugCentral/DrugBank, de novo→Google Patents 보조조회. LLM은 이 선택 정책을 우회할 수 없습니다.
